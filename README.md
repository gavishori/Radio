# רדיו נקי

נגן רדיו בדפדפן עם 66 תחנות: כל תחנות ישראל המרכזיות (כאן, גלגלצ, גלי צה״ל, 103, 100, 99, 102 ועוד) ותחנות ציבוריות מ-9 מדינות נוספות. תחנות עם פרסומות מסומנות, ואפשר להסתיר אותן.

בוחרים תחנה מתוך ריבועים, מסננים לפי מדינה ולפי נושא (ג'אז, קלאסי, רוק, חדשות ועוד) ושומרים תחנות ברשימת מועדפים.

**להאזנה:** https://gavishori.github.io/Radio/

הכול נמצא בקובץ אחד, `index.html`, בלי התקנות ובלי שרת. אפשר להוסיף תחנה משלכם עם כתובת סטרים, והיא נשמרת בדפדפן.
