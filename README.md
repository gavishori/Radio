# רדיו נקי

נגן רדיו בדפדפן עם 100 תחנות מישראל ומארה״ב: כל תחנות ישראל המרכזיות (כאן, גלגלצ, גלי צה״ל, 103, 100, 99, 102 ועוד), ותחנות מוזיקה אמריקאיות בג'אז, קלאסי, רוק, פופ, היפ-הופ וקאנטרי. תחנות עם פרסומות מסומנות, ואפשר להסתיר אותן.

בוחרים תחנה מתוך ריבועים מסודרים לפי התדר, מסננים לפי מדינה ולפי נושא (קאנטרי, מוזיקת עולם, רגוע, 70-90s, בלדות, אהבה ואינדי) ושומרים תחנות ברשימת מועדפים.

**להאזנה:** https://gavishori.github.io/Radio/

הכול נמצא בקובץ אחד, `index.html`, בלי התקנות ובלי שרת. אפשר להוסיף תחנה משלכם עם כתובת סטרים, והיא נשמרת בדפדפן.
